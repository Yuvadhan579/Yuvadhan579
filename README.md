🚗 Fuel Consumption Analysis & Prediction
`Mar 2025 – Jun 2025`  ·  `Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib` `Seaborn` `Streamlit`
An end-to-end ML system that predicts fuel consumption for commercial vehicles.
Built on 5,975 vehicle records with 4 input features: top speed, load capacity, driving behavior and environmental condition
Preprocessed with Pandas (label encoding, missing-value removal) and explored the data with histograms and a correlation heatmap
Trained and compared 4 regression models on an 80/20 split; Linear Regression came out best (MSE 1.08 · MAE 0.83 · R² 0.43)
Shipped a Streamlit app with dataset filters, actual-vs-predicted plots, an R² comparison chart and single-vehicle prediction with a selectable model
🚙 Vehicle Rental Management System
`Oct 2025 – Nov 2025`  ·  `Java` `NetBeans` `Maven` `OOP`
A console-based rental application built around clean object-oriented design.
12 classes applying abstraction, inheritance, polymorphism and encapsulation
Abstract `Vehicle` hierarchy (Car, Bike, Truck) overriding `calculateRent()`, which removed type-checking conditionals from the billing logic
`HashMap` for O(1) rental return lookup and a fixed-size circular buffer with O(1) insertion for the 10 most recent rentals
2 custom checked exceptions plus input validation so bad input never crashes the app
